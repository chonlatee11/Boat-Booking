## Phase Goal

**As a** developer, **I want to** scaffold services from a shared template, run the whole stack locally and watch one real event flow end-to-end with a single trace, **so that** every later service costs only business-logic time.

This plan's slice: **As a** developer, **I want to** write a state change and an outbox row in one transaction and see the event land on Redpanda with its trace context, **so that** no service ever publishes outside a transaction.
