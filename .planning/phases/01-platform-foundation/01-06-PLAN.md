<objective>
Stand up CI where none exists (D-21): Jenkins controller + SSH agent (docker.sock for testcontainers) and Harbor as the image registry, in one `deploy/ci/docker-compose.yml` that runs locally (`make ci-up`) and on the single EC2; plus a `Jenkinsfile` whose stages are `make` targets.

Purpose: PLAT-08 — every push builds images and runs unit + integration tests. Plan 13 later narrows builds to changed services, adds web/proto gates and folds everything into `make ci`.
Output: a green Jenkins build of the current branch and a verified push path into Harbor.
</objective>

## Phase Goal

**As a** developer, **I want to** scaffold services from a shared template, run the whole stack locally and watch one real event flow end-to-end with a single trace, **so that** every later service costs only business-logic time.

This plan's slice: **As a** developer, **I want to** push a commit and have Jenkins build and test it (and publish images to Harbor from main), **so that** integration tests — including the future capacity race test — run on every push, not just on my laptop.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git repo → Jenkins agent | Pipeline code executes with docker.sock (host root equivalent) |
| operator browser → Jenkins/Harbor UIs | Admin surfaces |
| Jenkins → Harbor | Credentialed image pushes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Elevation of Privilege | docker.sock in jenkins-agent | high | mitigate | Socket mounted only into the agent (not the controller); controller has 0 executors; builds only from CI_REPO_URL (own repo); Jenkins bound to 127.0.0.1; residual host-root risk inherent to D-21 accepted and documented in SUMMARY |
| T-06-02 | Spoofing | Jenkins UI/API | high | mitigate | JCasC local realm, random admin password in git-ignored .env, `allowAnonymousRead: false`, CSRF crumb required |
| T-06-03 | Spoofing | Harbor admin | high | mitigate | Non-default admin password generated into .env; project `boatbooking` private |
| T-06-04 | Information Disclosure | CI secrets | medium | mitigate | Secrets only in .env / JCasC env interpolation / Jenkins credentials store; Jenkinsfile uses withCredentials |
| T-06-05 | Tampering | Jenkins plugins, images, Harbor installer | medium | mitigate | Plugins pinned name:version; images pinned tags; Harbor installer pinned v2.15.2 from the official GitHub release URL over HTTPS |
| T-06-06 | Tampering | images pushed from unreviewed branches | medium | mitigate | Push stage `when { branch 'main' }` |
| T-06-SC | Tampering | package installs | low | accept | No npm/pip/cargo installs in this plan (apt packages inside the agent image come from Debian mirrors) |
</threat_model>
