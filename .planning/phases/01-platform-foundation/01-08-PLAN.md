## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| services → Collector (compose network) | Telemetry that could carry PII if services misbehave |
| operator browser → Grafana :3000 | Read access to all telemetry |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-08-01 | Information Disclosure | Grafana UI | medium | mitigate | Anonymous auth disabled; admin password from .env; published on 127.0.0.1 only |
