## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Kong → gateway | JWT-verified requests; public prefix unauthenticated |
| gateway → catalog | Internal token + verified claims |
| catalog.events → schedule DB | Another service's events mutate schedule state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Spoofing | client-supplied X-* headers through the gateway | high | mitigate | `ForwardClaims` deletes inbound claim/internal headers before setting verified ones; test sends a spoofed X-Operator-Id |
| T-11-02 | Spoofing | forged/refresh tokens at the BFF | high | mitigate | Gateway re-verifies RS256 + kind=access even behind Kong; tests for missing/expired/refresh tokens |
| T-11-03 | Tampering | malformed or oversized request bodies | medium | mitigate | 16 KiB MaxBytesReader; protojson rejects unknown fields; catalog validates again |
| T-11-04 | Tampering | replayed/duplicate BoatUpserted | high | mitigate | pkg/kafka processed_events idempotency; TestBoatUpsertedAppliedOnce |
| T-11-05 | Information Disclosure | public boats listing | low | accept | Boats are public catalog data (name, capacity, status); no operator-private fields beyond operator_id uuid |
| T-11-06 | Denial of Service | slow catalog | medium | mitigate | connect client http.Client timeout 5s; errors mapped to 5xx JSON without internals |
</threat_model>
