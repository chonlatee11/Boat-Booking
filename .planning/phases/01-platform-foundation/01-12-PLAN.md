## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → compose infra ports | Dev ports for psql/rpk/go run |
| service → other service's database | Must be impossible (database-per-service) |
| browser → Kong | Only public entry to the app |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Spoofing/Elevation | Go services reachable from the host | high | mitigate | No `ports` on Go services (verified by jq check); claim headers only via gateway + internal token |
| T-12-02 | Information Disclosure/Tampering | cross-service DB access | high | mitigate | init.sh revokes PUBLIC CONNECT and grants CONNECT only to the owning role; isolation-check.sh proves denial |
| T-12-03 | Information Disclosure | dev infra ports | medium | mitigate | Every published port bound to 127.0.0.1; dev-only passwords live in git-ignored .env |
| T-12-04 | Tampering (SQL injection) | init.sh service names | medium | mitigate | Names re-validated against `^[a-z][a-z0-9]*$` before SQL interpolation |
| T-12-05 | Denial of Service | Redpanda dev-container mode | low | accept | Dev-only flags (fsync relaxed); production durability settings are Phase 5 DEP-01 |
| T-12-SC | Tampering | goose build, images | low | mitigate | goose pinned v3.28.0 via proxy.golang.org; all images pinned by tag; no npm/pip/cargo installs |
