<objective>
Close PLAT-08 and D-22: one `make ci` that reproduces the Jenkins pipeline locally — every gate (Go lint, proto gates, unit, integration, migration validation, template smoke, web lint/typecheck/build) plus changed-services image scoping — and a final `Jenkinsfile` whose stages call exactly those targets, pushing to Harbor only from main.

Purpose: CI is the full quality gate for every later phase; changed-paths scoping keeps it fast as services multiply without ever skipping integration tests.
Output: `make ci` green locally; Jenkins green on the current branch.
</objective>

## Phase Goal

**As a** developer, **I want to** scaffold services from a shared template, run the whole stack locally and watch one real event flow end-to-end with a single trace, **so that** every later service costs only business-logic time.

This plan's slice: **As a** developer, **I want to** run `make ci` and get the exact verdict Jenkins will give, with images built only for services my change touched, **so that** pushing is never a surprise and CI stays fast.

   - `lint` gains web checks: `test -d apps/web/node_modules || npm --prefix apps/web ci`, then `npm --prefix apps/web run lint` and `npm --prefix apps/web run typecheck` (D-48: golangci + buf lint + eslint + tsc).
