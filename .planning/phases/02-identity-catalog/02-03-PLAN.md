<objective>
Extend catalog from "boats only" to operators and piers with the phase's single scoping rule: super_admin sees and writes everything; pier_admin reads/writes only piers in (operator_id, pier_ids); staff reads the same scope; everyone else is denied; no claims means the public projection.

Purpose: CAT-01, CAT-02 (data side) and CAT-06 (public piers) plus the AUTH-05 scoping pattern every later catalog plan (routes, prices, boats) reuses. Driven from tests over connect-go with forwarded claim headers (the gateway proxy lands in parallel plan 02-04).
Output: operators + piers tables, protos/events, `app.Scope`, handlers, integration tests.
</objective>

## Phase Goal

**As a** customer, staff member or pier_admin, **I want to** sign in with a one-time code and (as an admin) manage operators, piers, routes, boats and prices, **so that** customers can browse the catalog publicly while every admin only ever touches their own operator's piers. *(Restatement of the ROADMAP Phase 2 goal.)*

This plan's slice: **As a** super_admin, **I want to** create operators and their piers, and **as a** pier_admin edit only my piers, **so that** every pier on the map belongs to exactly one operator and no admin can touch another operator's data.
