## Phase Goal

**As a** customer, staff member or pier_admin, **I want to** sign in with a one-time code and (as an admin) manage operators, piers, routes, boats and prices, **so that** customers can browse the catalog publicly while every admin only ever touches their own operator's piers. *(Restatement of the ROADMAP Phase 2 goal.)*

This plan's slice: **As a** customer or admin, **I want to** sign in from the browser and stay signed in for 30 days, **so that** I only enter a code again when I sign out or my access changes.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05-01 | Information Disclosure | tokens exposed to JS | high | mitigate | Tokens only in httpOnly Secure SameSite=Lax cookies; JSON bodies carry user fields only (test asserts) |
| T-02-05-02 | Spoofing / Replay | stolen refresh token | high | mitigate | Single-use rotation; replay of a rotated token revokes the whole family (TestRefreshRotationAndReuseDetection) |
| T-02-05-03 | Elevation of Privilege | stale claims after role/pier change or disable | medium | mitigate | Refresh re-reads users row every time; access TTL 15 min bounds the window (D-10) |
| T-02-05-04 | Tampering (CSRF) | cookie-authenticated POST /auth/refresh, /auth/logout | medium | mitigate | SameSite=Lax blocks cross-site POST cookies; CORS allow-list with credentials; JSON content type forces preflight |
| T-02-05-05 | Denial of Service / brute force | /api/v1/auth/* | medium | mitigate | Route-level Kong limit 20/min/IP on top of D-03 per-destination limits |
| T-02-05-06 | Elevation of Privilege | super_admin bootstrap abuse | medium | mitigate | Only the operator-controlled SUPER_ADMIN_EMAIL env promotes; no API path creates super_admin |
| T-02-05-07 | Information Disclosure | enumeration via verify errors | low | accept | Only a holder of a valid code learns "disabled"; request path stays uniform (canon — /gsd-secure-phase) |
