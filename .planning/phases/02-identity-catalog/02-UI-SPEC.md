# Phase 02 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase touches **two** frontend surfaces:

- **`apps/web`** (customer, TH/EN, already scaffolded in Phase 1) — gains only the OTP login/verify screens (AUTH-01). No catalog browse UI this phase (CAT-06 ships as an API only; customer search/map UI is Phase 4 per CONTEXT.md's phase boundary).
- **`apps/admin`** (staff/pier_admin/super_admin, Thai-only, **does not exist yet** — Wave 0 scaffold gap per `02-RESEARCH.md`) — the OTP login screens plus CRUD for Operators, Piers, Routes (incl. cancellation policy + route prices), Boats, and Staff Users.

Both surfaces **must reuse the identical design system** already established in `apps/web` during Phase 1 — this contract does not invent new tokens, it extends the existing ones to a second app.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: icon-only buttons (archive/delete icon in table rows, map marker drag handle, photo-remove button) must have a minimum **44×44px** touch target regardless of the visual icon size, for tablet use at the pier (D-18/D-19 context — pier_admin may operate from a tablet). Every icon-only button carries an `aria-label` (TH) naming its action, e.g. "เก็บถาวร{entity}", "ลบรูปภาพ".

Focal points: list pages → the primary "เพิ่ม{entity}ใหม่" button (top-right, above the table); OTP screens → the destination input / `input-otp` field; Sheet/Dialog forms → the first field, with the submit button pinned at the footer.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (white, `oklch(1 0 0)`) | Page background, form surfaces |
| Secondary (30%) | `--card` / `--secondary` / `--muted` (near-white/light neutral grays) | Data table rows, cards, Sheet/Dialog surfaces, nav |
| Accent (10%) | `--primary` = `#0b6e99` | Primary CTA buttons, links, active nav item, focus ring |
| Destructive | `--destructive` (shadcn default red) | Archive/disable buttons and their confirmation dialogs only |

Accent (`#0b6e99`) reserved for: primary "เพิ่ม{entity}ใหม่" buttons, "ยืนยันรหัส"/"ส่งรหัส OTP" buttons, active sidebar nav item, text links, focus rings. Never used for status badges (those use semantic green/orange, not the brand accent) or for destructive actions.
